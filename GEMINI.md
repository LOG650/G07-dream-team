# Project: G07 - Dream Team (LOG650)

## Overview
This is a university project for the course LOG650. The repository contains documentation, data, and reports related to supply chain disruption and recovery.

## Directory Structure
- `000 templates/`: Course templates and reference styles.
- `004 data/`: Datasets for analysis (e.g., `global_supply_chain_disruption_v1.csv`).
- `006 scripts/`: Python scripts for data auditing and cleaning.
- `011 fase 1 - proposal/`: Project proposal.
- `012 fase 2 - plan/`: Project management plan.
- `014 fase 4 - report/`: Final project report.

## Contextual Instructions
- All documents should follow the APA 7th referencing style as per `000 templates/Referansestiler/APA 7th norsk v1.12.pdf`.
- Maintain a professional and academic tone in all generated content for the reports.
- Ensure that data analysis refers to the files in `004 data/`.
